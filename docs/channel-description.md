# The public channel's description (draft)

The UI and UX policy's rule for shared audiences (MSG6) asks the channel's description to say that posts are picked
automatically, and how to report a wrong one. The agent drafted it on 2026-11-19; the owner changes the live channel
(Telegram: the channel › Edit › Description). Replace `@HANDLE` with the account or bot readers should write to.

Telegram allows 255 characters. Pick one.

**Both languages (227 characters):**

```
وظائف لحديثي التخرج (IT، سيطرة، حاسبات) في البصرة أو عن بُعد، تُختار تلقائياً من قنوات وظائف عامة.
Entry-level IT/control/computer jobs in Basra or remote, picked automatically from public job channels.
خطأ؟ Wrong post? @HANDLE
```

**Arabic only (164 characters):**

```
وظائف لحديثي التخرج في تقنية المعلومات والسيطرة وهندسة الحاسبات في البصرة أو عن بُعد، يختارها برنامج تلقائياً من قنوات الوظائف العامة. منشور غير مناسب؟ راسل @HANDLE
```

**English only (161 characters):**

```
Entry-level IT, control and computer engineering jobs in Basra or remote, picked automatically by a program from public job channels. Wrong post? Message @HANDLE
```

"From public job channels" is only true once every watched source is public (republishing keeps its audience,
T13; #68). Check your chat list before using these words.
